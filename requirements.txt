# Troubleshooting
# ============================================================================

# Common issues and solutions:
#
# 1. "ModuleNotFoundError: No module named 'omni.timeline'"
#    Cause: Importing Isaac Lab modules before SimulationApp instantiation
#    Solution: Training scripts are configured correctly. Use provided scripts.
#
# 2. "Isaac Sim Crashes (Segmentation Fault)"
#    Cause: C++ template symbol parsing issues or resource limits
#    Solution: Use minimal training script with reduced environment count
#    Use: ./scripts/train_direct.sh (4 envs, 10 iterations for testing)
#
# 3. "Parameter Conflicts"
#    Cause: Overlapping argument definitions
#    Solution: Use fixed training scripts that avoid conflicts
#
# 4. "Module Import Errors"
#    Cause: Isaac Lab modules imported before SimulationApp instantiation
#    Solution: Use provided training scripts, which ensure correct import order
