## 1. 初始状态优化

### 1.1 优化目标

GO2W_ARM机器人在训练中难以从翻倒状态恢复站立，主要原因是：
1. 初始姿态随机化过于激进（±180°的角度和±0.5的角速度）
2. 初始高度过低（0-0.2m，接近地面）
3. 高度奖励函数为负权重（-5.0），实际上是惩罚而不是奖励

### 1.2 位置范围优化

**修改文件**: `velocity_env_cfg.py`

```python
"z": (0.0, 0.2) → (0.35, 0.5)       # 0-0.2m → 0.35-0.5m（提高75%）
```

## 3. 机械臂姿态优化

### 3.1 优化目标

减少机械臂在训练初期对平衡的干扰：
- 收起机械臂，降低质心高度
- 减少机械臂运动产生的动量
- 让机器人先学会腿部平衡

### 3.2 机械臂初始姿态调整

```python
# unitree.py - UNITREE_GO2W_ARM_ARX5_CFG
```

## 11. 故障排除

### 11.1 如果Mean Reward仍然很低

**可能原因**:
- 扭矩仍不足
- 随机化仍然过大
- 奖励权重不平衡

**解决方案**:
1. 进一步增大扭矩到45.0 N·m
2. 降低随机化范围
3. 调整奖励权重优先级

### 11.2 如果机械臂仍然干扰平衡

**可能原因**:
- 机械臂姿态不够紧凑
- 机械臂扭矩过大导致不稳定运动

**解决方案**:
1. 进一步收起机械臂
2. 降低机械臂刚度
3. 增加机械臂稳定性奖励

### 11.3 如果扭矩利用率过低

**可能原因**:
- 扭矩限制过大，浪费资源
- 动作scale过小

**解决方案**:
1. 降低扭矩限制到30.0 N·m
2. 增大动作scale
3. 调整执行器增益

### 11.4 如果扭矩利用率过高

**可能原因**:
- 扭矩限制不足
- 负载过重

**解决方案**:
1. 进一步增大扭矩到45.0 N·m
2. 降低机械臂重量或姿态
3. 优化机械臂运动规划

## 12. 关键洞察

1. **扭矩是关键**: 对于20kg的系统，23.5 N·m可能不足以快速恢复姿态
2. **质心管理**: 收起机械臂降低质心，显著提高稳定性
3. **渐进式学习**: 先稳定平衡，再展开机械臂
4. **扭矩利用率**: 监控扭矩使用情况，避免过度或不足
