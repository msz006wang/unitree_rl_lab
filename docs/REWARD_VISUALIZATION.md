## 🔄 奖励函数相互作用

### 主要冲突关系

```
速度精度 ⟷⟷ 能耗效率
  ↕                 ↕
  ├─ 高速度需要大力矩 (冲突)
  └─ 快速运动增加能耗

稳定性 ⟷⟷ 机动性
  ↕                 ↕
  ├─ 平地稳定性限制快速转向
  └─ 过度稳定可能降低灵活性
```

### 协同作用

```
姿态控制 + 步态质量 → 整体运动质量
动作平滑 + 对称性 → 控制流畅性
速度跟踪 + 能耗效率 → 高效精准控制
```

## 📈 奖励函数时间演化

### 学习早期阶段 (0-1M steps)

```
激活奖励: 速度跟踪 + 基本稳定性
学习重点: 完成主要运动任务
典型策略: 基本移动，忽略效率
```

### 学习中期阶段 (1-5M steps)

```
激活奖励: 全部奖励 + 动作平滑
学习重点: 优化运动质量 + 降低能耗
典型策略: 改进步态 + 优化力矩
```

### 学习后期阶段 (5M+ steps)

```
激活奖励: 精细化优化 + 特殊场景
学习重点: 极致化 + 边界情况处理
典型策略: 高效稳定 + 鲁棒性
```

## 🧪 奖励函数调试指南

### 问题诊断

| 现象 | 可能原因 | 检查项 |
|------|-----------|---------|
| 机器人不移动 | 速度跟踪权重过低 | track_lin_vel_xy_exp权重 |
| 能耗过高 | 效率惩罚过低 | joint_torques, joint_power权重 |
| 不稳定翻倒 | 稳定性惩罚不足 | base_height, flat_orientation权重 |
| 步态不自然 | 步态奖励权重过高 | feet_contact, feet_air_time权重 |
| 控制抖动 | 动作平滑不足 | action_rate, action_mirror权重 |

### 权重调整策略

1. **逐步调整**: 每次调整一个奖励项，观察效果
2. **保持平衡**: 增加某项权重时，检查对其他项的影响
3. **长期观察**: 权重调整后训练足够长时间评估
4. **任务导向**: 根据具体应用场景调整权重

## 🎯 总结

### 奖励函数设计原则

1. **多目标平衡**: 在速度、效率、稳定性、安全性间找到最优平衡
2. **物理驱动**: 所有奖励基于真实的物理量（力、速度、位置）
3. **可学习性**: 连续、可微的函数，便于梯度优化
4. **鲁棒性**: 软约束避免策略崩溃，硬约束确保安全性

### 关键洞察

1. **主导目标**: 速度跟踪奖励占主导地位，确保任务完成
2. **安全第一**: 关节限制惩罚权重最高(-5.0)，确保硬件安全
3. **逐步优化**: 次要目标权重递减，形成层次化优化结构
4. **适应性**: 不同机器人和场景可以灵活调整权重配置

### 未来改进方向

1. **自适应权重**: 根据学习进度动态调整权重
2. **任务分解**: 不同任务阶段使用不同的权重配置
3. **多模态支持**: 支持站立、坐下等不同模式
4. **环境感知**: 根据地形复杂度自适应调整奖励
