#### 2. 新增机械臂稳定性奖励

**新增函数**: `arm_stability` 在 [rewards.py](source/unitree_rl_lab/unitree_rl_lab/tasks/locomotion/mdp/rewards.py) 中实现

**功能描述**:
- 计算机械臂关节位置方差
- 奖励低方差（稳定性高）
- 考虑运动速度（运动时更稳定）
- 权重: 2.0（较高权重专门针对机械臂）

**实施代码**:
```python
# rewards.py 中的新增函数
def arm_stability(env, asset_cfg, stability_window=100):
    joint_variance = torch.var(arm_joints, dim=-1)
    stability_reward = torch.exp(-joint_variance * 10.0)
    motion_bonus = torch.clamp(arm_velocity / 5.0, 0.0, 1.0)
    return stability_reward * (1.0 + motion_bonus)
```

**集成方式**:
- 在 [velocity_env_cfg.py](source/unitree_rl_lab/unitree_rl_lab/tasks/locomotion/robots/go2w_arm/velocity_env_cfg.py) 的RewardsCfg类中添加
- 配置为: `arm_stability = RewTerm(func=mdp.arm_stability, weight=2.0, params={...})`
